# F296~F301 设计定案:启动页过滤/拨号动画、节点状态、编辑器查找、书签宽度与 `~`

> 2026-09-28 /grill-me 逐条定案。一个切片、一次发版(v0.1.119)。
> 实现顺序:F296 → F300 → F301 → F299 → F297 → F298(由易到难,互不依赖)。

## F296 启动页会话列不显示 SFTP 会话

- 只动第二列(会话)。`session_order` 加过滤 `protocol != Sftp`。
- 项目列、历史列不变(项目本来就挂在终端节点上;历史是现场快照,SFTP 标签照恢复)。
- 空态文案:全是 SFTP 时第二列说「还没有会话」,不是「没有匹配的会话」——
  判据改成「过滤掉 SFTP 之后还剩不剩」,不看原始表长度。

## F297 点击后立刻显示「连接中…」

- 项目行、会话行被点之后,该行右侧立刻出现 spinner +「连接中…」;在途期间**再点这一行不理**,
  其他行照常可点(两条拨号同时在途是常态,F205)。
- 成功:照旧切走(第一个标签立起来,launcher 消失)。失败/取消:行恢复原样,错误走既有报告通道。
- **不建影子状态**:「哪些在拨」每帧从 `self.dials`(F205 票据台账)现算——
  票里 `user_initiated && session_id` 给会话列,新增的 `project_id` 给项目列。
  票据的生命周期(`issue` → `ConnectOk/ConnectErr` 里 `claim`)就是动画的生命周期。
- 历史列不做:单击当场 `restore_tabs`,界面立即切走,本来就没有空窗期。

## F298 标题条右侧显示节点状态

- 位置:每块 pane 现有标题条的右侧(按钮组左边),如 `内存 43% · 磁盘 71% · JP`。
- 粒度:按连接(`HostConn`)采样,同连接的所有 pane 共享一份。
- 采样:走 exec channel(同 F124 `tick_tmux_bootstrap` 的先例)。
  - 内存 = `(MemTotal − MemAvailable) / MemTotal`,读 `/proc/meminfo`;悬停给绝对值。
  - 磁盘固定 `/`,`df -Pk /`。
  - 10 秒一次。
- 国家:远端 `curl -s --max-time 5 https://ipinfo.io/country`,没有 curl 回落 wget。
  连上时取一次,之后 5 分钟一次;点这一格手动刷新。
- 阈值:≥90% 用既有 `warn` 语义色。
- 失败:该格显示 `--`,悬停写原因;**不弹窗**(多 pane 同时失败会连弹)。
- 窄条:这一段先于左侧标题截断/隐藏(给标题保底 `min(标题宽, 220pt)`)。
- SFTP 节点标签没有标题条,不显示;非 Linux 远端(没有 `/proc/meminfo`)只省掉内存那格。
- 回送:结果写进 `HostConn.stats` 的共享格子(`Arc<Mutex<..>>`,同 `BootstrapFlags` 的
  跨线程模式),再发一条无负载的 `UserEvent::NodeStatsUpdated` 让界面重绘。
  不带世代路由:数据本身就挂在那条连接上,连接没了格子跟着没。
- 定时:下一次采样时刻并入 `next_timer_wake`(T3/T7 唯一汇合点)。

## F299 内置编辑器 Ctrl+F 查找

- 只查找,不替换、不高亮全部匹配。
- Ctrl+F 在正文上方开查找条,预填当前选区(单行时),输入即跳到第一处匹配。
- Enter / F3 下一个,Shift+Enter / Shift+F3 上一个,首尾回绕。
- 显示 `3/17`;`Aa` 切大小写(默认不区分);Esc 关条、焦点回正文。
- 当前匹配高亮并滚入视野。技术约束:查找框持有焦点时 `TextEdit` 不画正文选区,
  所以当前匹配用 overlay 画(`galley.pos_from_ccursor` + `galley_pos`);关条时把正文
  选区设成那处匹配。
- 标题栏加一颗搜索图标按钮(tooltip「查找 (Ctrl+F)」)作为可见入口;
  不进快捷键一览(编辑器那张表没有行,补一节牵连占用者冲突判定,不值)。

## F300 书签下拉不折行

- 根因:egui `Area` 尺寸棘轮(F259/F263 同形)——菜单 Area 记住上一帧内容宽,短书签
  (`/`)之后换成长路径,每个按钮被压成 11pt 宽、19 行的竖条(已无头复现)。
- 修法:菜单闭包里 `ui.set_max_width(屏宽 × 0.6)` 切断棘轮;按钮 `TextWrapMode::Extend`;
  超过上限的路径**按像素**中段省略(`reveal::elide_middle` + 二分字符预算),悬停给完整路径
  和自定义名。
- 守护必须是「先短后长」两帧序列(单画一条长的首帧预算够宽,看不出问题)。

## F301 书签支持 `~`

- 书签路径可以是 `~` 或 `~/…`,点下去解析到**这一栏**连接用户的主目录(远端 = SFTP 登录
  目录;本地 = 本机 home)。点击发 `FileAction::GotoInput`,复用两栏既有的解析通路
  (`resolve_remote_input` / `resolve_local_input`)。
- ★ 判定先解析再比较(只对 `~` 开头的书签解析;其余照旧字面比较)。
  取消收藏时 `BookmarkRemove` 传**命中那条书签的原始路径**(否则删不掉 `~`)。
- 正在主目录时点 ☆ 存成 `~`;子目录仍存绝对路径。
- `default_local` / `pick_default_local` 也展开 `~`。
- 本机 home 缓存一次(`OnceLock`),不每帧系统调用(T3)。

## 否掉的备选

- F297 在 `UiState` 记一张「在拨表」:影子状态,`ConnectErr` 漏清一次就永远转圈(F160~F163 同形)。
- F298 用 `UserEvent` 带世代号 + host_ix 回送数据:要按世代路由、host 下标在换节点后会漂;
  数据挂在连接上的共享格子没有这个问题。
- F298 本地查 ipinfo:测的是 Windows 这头的出口,不是远端节点走的 VPN 出口——用户要的是后者。
- F300 固定菜单宽度:短书签也铺满 60%,难看;按内容宽 + 上限封顶才对。
