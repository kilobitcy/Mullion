# F375~F378 设计:双击选 URL / URL 不跳侧栏 / Alt 复制人称互换 / 隧道入口变浅

> 2026-11-18 grill 定案。来源:用户对 v0.1.146 提的三条。一个批次,发 v0.1.147。

## F375 双击选中完整 URL

事实:F371 的路径字符集(`selection::is_path_char`)不含 `:`,`https://github.com/x` 双击得
`//github.com/x`;端口 `:8080`、查询 `?a=1&b=2`、锚点 `#x` 同样截断。

决策:
1. 双击点向两侧按 **URL 字符**(路径字符 + `:?&#!$*,;`)扩最大连续段(跨行同 F371「写满右缘」)。
   段里找 `://`,其前紧挨的 scheme(字母开头,字母数字 `+.-`)≥1 字符 → 这是一条 URL,
   范围 = scheme 起点 → 段尾(若段里还有下一条 URL,止于它的 scheme 之前),**剥尾部 `.,;:!?`**。
   双击点落在这个范围内才用;否则走 F371 路径判据。
2. `()[]`、引号、中文不是 URL 字符 —— `[链接](https://…)` 切干净;含括号的 URL(维基)截断,接受。
3. 无 scheme 的 `host:8080/x`、`user@host:/p` 仍按路径,冒号处截断,接受。
4. 判据是 `mullion-term::selection` 的纯函数,配 VT fixture。

## F376 Ctrl+Shift+B 遇到 URL 不跳

事实:`files::reveal::parse` 的门 4 只要求含 `/`,`https://…` 会被当成 `<cwd>/https:/…` 跳,
弹「不存在」。

决策:剥壳之后以 `scheme://` 开头 → `None`(含 `file://`)。效果同「选区没有路径」:按 F374
查最近一次复制,没有就关栏。F374 的复制记忆走同一 `parse`,自然覆盖。

## F377 Alt 复制人称双向互换

推翻 F365「不做反向我→你」。一遍逐字映射:你/您 → 我,我 → 你(「我们」↔「你们」随之)。
toast 次数 = 两方向合计。不做语义判断(「自我」也换),靠 Warn toast 兜底。

## F378 隧道入口变浅

1. 状态栏隧道指示器**常驻**:一条没配时灰色「隧道 0」(推翻 F369「没配不占格」)。
2. 浮层底部加「+ 新建隧道」:开会话管理器隧道页 + 空编辑缓冲(同列表「+ 新建隧道」);
   右栏隧道表单有未保存改动时不换(同浮层「编辑」)。保留「管理隧道…」。
3. 「会话」菜单在「项目管理器」后加「隧道管理器…」,直接落隧道页。
4. 不加快捷键(低频,且每占一个 Ctrl+Shift 组合就少一个透传给远端的键)。
5. 新文案过 T9 字形白名单。

## 人工验收(无头验不了)
- 双击各种 URL(带端口/查询/锚点、句末、Markdown 链接里、tmux 硬折两行)。
- 选中 URL 按 Ctrl+Shift+B 不弹「不存在」。
- Alt 拖选「我建议…需要你拍板」→ 粘出「你建议…需要我拍板」。
- 没配隧道时状态栏有灰色「隧道 0」,点开能新建;菜单「隧道管理器…」直达隧道页。
