# F379~F385 设计定案(grill 2026-11-20)

七条均只动 `mullion-app`,不涉及 Android。一条一提交,F381 先于 F384(同改备忘浮层)。

## F379 打开项目确认框:回车继续、Esc 取消
- F223 `show_open_confirm`:回车 = 继续打开,Esc = 取消。回车走 `project_nav::take_enter`
  (组字确认那一下不算,F314/F316)。「继续打开」画成焦点样式,让人看得出回车落在哪。
- F224 踢人框**不接回车**(后果落在别人身上,留一次真点击),只接 Esc = 取消。

## F380 SFTP 传输进度改百分比
- 汇总行 `剩余 mm:ss` 换成总进度 `xx.xx%`(已传字节/总字节),速率保留;总字节为 0 显示 `0.00%`。
- 每条任务右侧也改两位小数。
- 封顶:未真传完不显示 `100.00%`(向下取整到 0.01)。删 `eta()`。

## F381 备忘显示添加时间
- 本地时区 `YYYY-MM-DD HH:MM`,正文下方一行小号 `fg_muted`。
- `created_at` 解析失败(含空串)不显示该行。只改浮层,项目管理器不动。

## F382 国家格手动刷新等待动画
- 只对用户点击那一次转圈;5 分钟自动刷新不转。
- `NodeStats` 加手动待决标志:点击置位;结果回来(Ok/Failed 都算)、`reset_schedule` 清。
- 自绘转圈弧替换国家文字、占同宽;hover「正在查询出口国家…」。在途不叠发(沿用 busy 闸)。
- 转圈时 `request_repaint_after(100ms)`,不转不请求(T3/T7)。UI 侧硬上限 30 秒。

## F383 菜单图标
- 「会话」「配置」「关于」三个菜单每项左侧 16 点图标槽,线条自绘(T9),颜色随文字。
- 对照:会话管理器=终端框 `>_`;分组管理器=叠放方块;项目管理器=`Project`;隧道管理器=左右双向箭头;
  导入 ssh config / 导入配置=箭头进托盘;导出全部配置=箭头出托盘;导出脱敏日志=文档;
  恢复上次的现场=带逆时针箭头的时钟;退出=电源;显示/隐藏标题条=顶栏加粗窗口;
  文件面板=左栏加粗窗口;立刻备份到云=云+上箭头;设置=齿轮;关于=`Info`。
- 新图标登记 `Glyph::ALL`;源码守护:菜单闭包内不得出现裸 `ui.button(`。

## F384 编辑已有备忘
- 双击正文进入编辑(单击不进),原地多行框预填原文,同时只一条在编辑。
- 回车保存、Shift+回车换行、Esc 放弃本次编辑(不关浮层)、组字回车走 `take_enter` 闸。
- 点浮层外 / 转去编辑另一条 = 自动保存。保存为空 = 取消(不隐式删除)。
- `created_at` 不变。落盘走 `MemoOut::Edit { old, new }` 读-改-写;磁盘上原条已不在则报错刷新,不复活。

## F385 隧道列表重排
- 三行:①状态圆点 + 名称(`fg_strong`,稍大)… 右侧状态文字 + 启停按钮;②转发串(正常前景色,
  端口前加 `:`),未命名时标题即转发串、省掉这一行;③「经 会话(user@host)」`fg_dimmer` 小号,悬垂仍红。
- 状态常驻:未启动 = 灰空心圆 + 「未启动」;运行绿实心;重连黄;失败/停止红;他窗口(F338)同位。
- 条目之间 `separator`;整条可点选中、整条背景高亮、右键克隆挂整条。
- 状态文字放不下时挪到第三行末尾;名称截断不挤按钮。
