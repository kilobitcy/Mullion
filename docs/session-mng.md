下面按分组列出一份比较完整的清单，标了 **[必填]**、**[常用]**、**[进阶]**，你可以按此决定“基础/高级”两级 Tab 的划分。

## 1. 会话标识与组织
- 会话名称 **[必填]**
- 所属文件夹 / 分组（树形路径）**[常用]**
- **图标**：内置图标库（Linux/Ubuntu/CentOS/Debian/Windows/Docker/K8s/路由器/数据库…）、emoji、自定义上传、或按主机名自动匹配发行版 logo
- **颜色**：标签色（hex）+ 作用范围（标签页、会话树条目、终端顶部色条、窗口边框、状态栏）
- 标签 tags（可多选，用于筛选）**[常用]**
- 备注 / 描述
- 是否收藏、排序权重
- 快捷别名（供快速连接命令行使用）**[进阶]**
- 是否继承父文件夹配置（哪些字段继承、哪些覆盖）**[进阶，但建议早定]**

## 2. 连接
- 协议：SSH / SFTP / Telnet / Rlogin / Serial / 本地 Shell **[必填]**
- 主机地址（IP / 域名）**[必填]**
- 端口（默认 22）**[必填]**
- IP 协议族偏好：自动 / IPv4 / IPv6
- 连接超时（秒）
- 自动重连：开关、重试间隔、最大次数 **[常用]**
- Keepalive：发送间隔、TCP keepalive 开关
- 禁用 Nagle 算法（低延迟）**[进阶]**
- 启动时自动连接 / 随工作区恢复 **[常用]**

## 3. 身份验证
- 用户名 **[必填]**
- 认证方式（可多选、可排序）：密码 / 公钥 / 键盘交互 / GSSAPI-Kerberos / PKCS#11 智能卡 **[必填]**
- 密码（存入系统钥匙串或主密码加密，不明文落盘）
- 私钥来源：文件路径 / 内置密钥库 / ssh-agent / Pageant / 1Password·系统 agent **[常用]**
- 私钥口令（passphrase）、是否记住
- Agent 转发（ForwardAgent）**[进阶]**
- 二次验证：OTP/TOTP 自动填充、验证码提示匹配规则 **[进阶]**
- 登录提示自动应答（expect / send 列表，用于交互式登录）**[进阶]**
- 主机密钥策略：严格校验 / 首次接受 / 忽略；known_hosts 文件路径 **[常用]**

## 4. 跳板机与代理
- ProxyJump 跳板链（可多级，引用已有会话或独立填写）**[常用]**
- 或自定义 ProxyCommand **[进阶]**
- 网络代理：类型（HTTP / HTTPS / SOCKS4 / SOCKS5 / 系统代理）、主机、端口、认证账号密码

## 5. 隧道 / 端口转发
- 本地转发（Local，-L）：本地地址:端口 → 目标地址:端口，列表
- 远程转发（Remote，-R）
- 动态转发 / SOCKS 代理（Dynamic，-D）
- X11 转发：开关、DISPLAY、MIT-MAGIC-COOKIE
- 每条规则的启用开关、备注、连接时自动建立 **[常用]**

## 6. SSH 协议参数 [多为进阶]
- 协议版本、密钥交换算法（KEX）优先级
- 对称加密算法（Ciphers）列表与顺序
- MAC 算法列表
- 主机密钥算法列表
- 压缩开关与级别
- 客户端标识字符串（Client version banner）伪装
- 允许的 SSH 扩展 / send env 环境变量（如 LANG、TERM 之外的自定义 env）

## 7. 终端
- 终端类型 TERM：xterm-256color / xterm / vt100 / linux / ansi **[常用]**
- 字符编码：UTF-8 / GBK / GB18030 / Big5 / EUC-JP / Latin-1，及是否自动探测 **[常用]**
- Backspace 发送：BS(^H) / DEL(^?)
- Delete 键、Home/End 键序列风格
- 回车发送：CR / CR+LF
- 本地回显、行模式（Telnet 场景）
- 自动换行、反向换行
- 滚动缓冲区行数（scrollback）**[常用]**
- 光标形状（块/竖线/下划线）、是否闪烁
- 铃声：静音 / 系统提示音 / 视觉闪烁
- 鼠标：选中即复制、右键行为（粘贴/菜单）、支持鼠标上报（应用内 vim/htop）
- 功能键映射方案、Alt 作为 Meta、AltGr 处理 **[进阶]**
- 空闲自动断开时长；空闲时发送保活字符 **[进阶]**

## 8. 外观
- 初始窗口尺寸（列 × 行）或自适应
- 字体族、字号、行高、字间距、连字（ligatures）
- 粗体处理：使用亮色 / 使用粗体字重
- 配色方案（引用全局主题或会话独立覆盖）**[常用]**
- 前景色、背景色、光标色、选中区颜色（覆盖项）
- 背景透明度、模糊
- 背景图片：路径、平铺方式、透明度 **[进阶]**
- 深/浅色模式下的颜色映射（若你的 icon/color 要跟随系统主题，这项必须有）

## 9. 日志与录制
- 自动记录会话日志：开关
- 日志目录与文件名模板（支持 `%HOST% %DATE% %TIME% %SESSION%` 变量）
- 追加 / 覆盖 / 按日期切分
- 是否记录时间戳、是否剥离 ANSI 转义序列
- 敏感信息脱敏规则 **[进阶]**
- 会话录制（asciinema 式回放）**[进阶]**

## 10. 文件传输 / SFTP
- 默认本地目录、默认远端目录
- 目录初始化命令（cd 到某路径）
- ZMODEM/XMODEM 支持与自动接收
- 传输模式：ASCII / 二进制 / 自动；同名文件冲突策略（覆盖/跳过/重命名/询问）
- 保留权限与修改时间、并发连接数 **[进阶]**

## 11. 登录后自动化
- 登录后自动执行的命令列表（逐行发送，可设延时）**[常用]**
- 登录脚本文件（Shell/JS 脚本引擎）**[进阶]**
- 初始工作目录
- 自动附加到 tmux / screen 会话（会话名、是否新建）**[实用，很多人需要]**
- 环境变量注入

## 12. 安全与防误操作
- 环境等级标记：开发 / 测试 / 预发 / 生产 —— 这项和你的颜色方案天然搭配（生产=红）**[强烈建议]**
- 执行危险命令二次确认（`rm -rf`、`shutdown`、`reboot` 关键词列表）
- 只读模式（禁止输入）
- 连接前确认弹窗
- 是否允许被“多会话广播/同步输入”包含 **[常用]**
- 是否允许写入剪贴板 / 多行粘贴前确认

## 13. Serial 专用（若支持串口）
波特率、数据位、停止位、校验位、流控（None/XON-XOFF/RTS-CTS）、串口设备号。

## 关于 icon 与 color 的字段设计建议

```
icon:  { type: "builtin" | "emoji" | "custom", value: "ubuntu" | "🐧" | "/path/a.png" }
color: { value: "#E5484D", applyTo: ["tab", "treeItem", "topBar", "border"],
         lightVariant: "#C62828", darkVariant: "#F16A6A" }
```

三个容易被忽略的点：

1. **颜色语义化优于自由取色**。建议预设 6–8 个带含义的色板（生产/预发/测试/开发/自定义），既保证深浅主题下的对比度，也让团队内颜色含义一致。允许自由 hex，但默认走色板。
2. **继承机制**。图标和颜色最好能从文件夹继承（例如「生产环境」文件夹下所有会话默认红色），字段用「继承 / 覆盖」三态而非简单布尔。
3. **自动推断**。首次连接后读取 `/etc/os-release` 或 SSH banner，自动建议对应发行版图标，比让用户手选体验好很多。
